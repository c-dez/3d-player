# 3D Player Scene:
## Objetivo
    - Debe ser capaz de copiar y pegar en cualquier proyecto de godot y funcionar 

## Instrucciones
    - Parametros de movimiento y sensibilidad de camara se pueden modificar desde inspector de nodo Player
    -Los bindings de movimiento son: "left,right,up,down"
    -Binding de salto: "jump"
    - Esto es lo unico que debe de modificarse en Godot

## Incluye
        - parametros exportados
        - movimiento "wasd" 
        - gravedad personalizable
        - salto
        - camara tercera persona  controlada por mouse
